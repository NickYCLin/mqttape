MQTTape 隱私權政策

MQTTape 是開源 MQTT 用戶端。MQTTape 不提供由專案營運的帳號、應用程式分析、遙測端點或廣告服務；MQTTape 維護者不會收集應用程式使用資料。

網路通訊

  • 當你連線、訂閱、發布或重播擷取內容時，MQTTape 會與你設定的 Broker 交換 MQTT 資料。該 Broker 由你或其營運者控制，並適用營運者自己的隱私權作法。
  • 已安裝的桌面版會定期查詢 GitHub Releases 是否有應用程式更新，並可能在背景下載可用更新。GitHub 可能取得 IP 位址與 User Agent 等標準連線中繼資料；請參閱 GitHub 隱私權聲明。
  • Web Lite 由 GitHub Pages 提供，且只會連線至你選擇的 WebSocket Broker。GitHub Pages 請求適用 GitHub 隱私權聲明。
  • 只有在你選擇時，MQTTape 才會開啟外部文件或下載連結。

MQTTape 不會把 Broker 憑證、擷取內容、已儲存設定檔或 TLS Private Key 傳送給維護者。

本機資料

桌面版設定檔保存在 Electron 的本機 user-data 目錄。密碼與 Private Key Passphrase 會透過作業系統支援的 Electron safeStorage 加密；MQTTape 不會退回以純文字保存秘密。Web Lite 可以在瀏覽器儲存空間保存非敏感的連線偏好，但不會保存密碼或憑證路徑。

擷取內容保留在本機，而且只會在你要求匯出時建立檔案。匯出的擷取檔不含密碼、Passphrase 或本機憑證路徑。你可以隨時從裝置移除設定檔與已匯出的擷取檔。

MQTTape 會在本機裝置保存最多 1,000 筆已解析的 LoRaWAN Downlink 狀態事件，以便跨應用程式重新啟動關聯請求與後續確認。歷史可能包含裝置與應用程式識別碼、Topic、關聯識別碼、時間戳記、訊框中繼資料與平台錯誤文字，但不包含原始 MQTT Payload 或 Broker 憑證。你可以從 Downlinks 畫面匯出或清除歷史。

解除安裝桌面版會使用作業系統的一般應用程式移除控制；依作業系統行為，本機應用程式資料可能需要另外移除。

政策異動與問題

本政策的重大變更會發布在原始碼 repository。如有問題，請在 MQTTape issue tracker 提出。

此靜態頁面不載入第三方 script、分析服務、追蹤像素或 CDN 資產。

MQTTape Privacy Policy

MQTTape is an open-source MQTT client. It does not provide a project-operated account service, analytics service, telemetry endpoint, or advertising service. The MQTTape maintainers do not collect application usage data.

Network communication

  • When you connect, subscribe, publish, or replay a capture, MQTTape exchanges MQTT data with the broker address you configured. That broker is controlled by you or its operator and is subject to the operator's privacy practices.
  • Installed desktop builds periodically query GitHub Releases for application updates and may download an available update in the background. GitHub may receive standard connection metadata such as your IP address and user agent; see the GitHub Privacy Statement.
  • Web Lite is delivered by GitHub Pages and connects only to the WebSocket broker you select. GitHub Pages requests are subject to the GitHub Privacy Statement.
  • Links to external documentation or downloads are opened only when you choose them.

MQTTape does not send broker credentials, capture contents, saved profiles, or TLS private keys to the maintainers.

Local data

Desktop profiles are stored in Electron's local user-data directory. Passwords and private-key passphrases are encrypted through the operating system with Electron safeStorage; MQTTape does not fall back to plaintext secret storage. Web Lite can store non-secret connection preferences in browser storage but does not save passwords or certificate paths.

Captures are held locally and are exported only when you request an export. Exported captures omit passwords, passphrases, and local certificate paths. You can remove saved profiles and exported capture files from your device at any time.

MQTTape stores up to 1,000 parsed LoRaWAN downlink status events on the local device so requests and later acknowledgements can remain associated across app restarts. This history can include device and application identifiers, topics, correlation identifiers, timestamps, frame metadata, and platform error text. It does not include raw MQTT payloads or broker credentials. You can export or clear the history from the Downlinks view.

Uninstalling the desktop application uses your operating system's normal application removal controls; depending on the operating system, local application data may need to be removed separately.

Changes and questions

Material changes to this policy will be published in the source repository. For questions, open an issue in the MQTTape issue tracker.
